# Data Folder Structure - Updated

## New Structure

The `/data` folder now has **4 subdirectories**:

```
/data/
├── batch_input/            # Log files for batch.py processing
│   ├── K5ABC.log
│   ├── W5XYZ.log
│   └── N5TEST.log
│
├── database/               # SQLite database
│   └── laqp.db
│
├── final_reports/          # Final HTML reports with all leaderboards
│   ├── final_report_2026.html
│   ├── final_report_2025.html
│   └── final_report_2024.html
│
└── reference_data/         # Static reference files (read-only)
    ├── LA_Parish_Abbrevs.txt
    └── WVE_Abbrevs.txt
```

## What Changed

### Removed Folders
- ❌ `/data/logs/incoming/` → Now `/data/batch_input/`
- ❌ `/data/HTML_RESULTS/` → Now `/data/final_reports/`
- ❌ Direct files in `/data/` → Now in `/data/reference_data/`

### Removed Files
- ❌ `html_results.py` - No longer used (deleted)

### New Organization

**batch_input/**
- Contains `.log` files for batch processing
- Files placed here are processed by `batch.py`
- Web uploads still go to database directly (no file saved)

**database/**
- Contains only `laqp.db`
- Clean separation of database from other data

**final_reports/**
- Contains generated HTML files
- One file per year: `final_report_YYYY.html`
- Generated by `generate_final_report.py`
- Served by `/results` page

**reference_data/**
- Static files that never change
- Parish abbreviations
- State/province/DX abbreviations
- Mounted read-only in Docker

## Docker Volumes

### docker-compose.yml

```yaml
volumes:
  # Single volume for all persistent data
  - laqp-data:/data
  
  # Mount reference data from host (read-only)
  - ./data/reference_data:/data/reference_data:ro
  
  # Mount config from host (read-only)
  - ./config:/app/config:ro
```

### Volume Contents

```bash
# Check volume structure
docker-compose exec laqp-web ls -la /data/

# Should show:
# batch_input/
# database/
# final_reports/
# reference_data/
```


## Migration from Old Structure

If you have existing data in old structure:

```bash
# SSH into container
docker-compose exec laqp-web bash

# Or on Fly.io
flyctl ssh console

# Move data to new structure
mkdir -p /data/batch_input /data/final_reports /data/reference_data

# Move batch logs
mv /data/logs/incoming/*.log /data/batch_input/ 2>/dev/null

# Move final reports
mv /data/HTML_RESULTS/*.html /data/final_reports/ 2>/dev/null

# Move reference data
mv /data/*.txt /data/reference_data/ 2>/dev/null

# Verify
ls -la /data/batch_input/
ls -la /data/database/
ls -la /data/final_reports/
ls -la /data/reference_data/

exit
```

## Benefits of New Structure

✅ **Clearer organization** - Each folder has one purpose
✅ **Easier backups** - Database separate from inputs/outputs
✅ **Read-only reference data** - Can't be accidentally modified
✅ **Simpler paths** - No nested `/incoming/` directories
✅ **Better Docker mounts** - Single volume for all persistent data

## Quick Reference

| Old Path | New Path | Purpose |
|----------|----------|---------|
| `/data/logs/incoming/` | `/data/batch_input/` | Batch log files |
| `/data/database/laqp.db` | `/data/database/laqp.db` | ✅ Same |
| `/data/HTML_RESULTS/` | `/data/final_reports/` | Final HTML reports |
| `/data/*.txt` | `/data/reference_data/*.txt` | Reference files |

All Docker and Fly.io configuration files have been updated to reflect this new structure!
